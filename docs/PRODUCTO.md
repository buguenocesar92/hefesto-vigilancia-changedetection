# Servicio Hefesto
Oferta: configurar seguimiento de páginas acordadas, filtros, frecuencia, destinatarios y mantenimiento mensual. Cobrar según páginas, complejidad de extracción e historial, no solo por cantidad de solicitudes.

Casos: detectar cambios en catálogos/proveedores, documentación, avisos institucionales o páginas propias. No se ofrece asesoría financiera, vigilancia de personas ni captación automática de datos privados. Respetar límites de cada sitio y detener revisiones que fallen repetidamente.

El historial es observación técnica; no se presenta como evidencia certificada ni archivo legal. Configurar retención según capacidad y necesidad. Añadir Playwright solo como ampliación revisada; no está instalado aquí.
